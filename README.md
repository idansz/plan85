# תוכנית 85 · אפליקציית אנדרואיד

אפליקציה מקומית: כל הממשק נמצא בתוך ה-APK, והיא עובדת גם בלי אינטרנט. הנתונים (שקילות, אימונים, תפריט) נשמרים על הטלפון.

## בנייה דרך GitHub (בלי להתקין כלום)

1. צור ריפו **פרטי** חדש ב-GitHub, למשל `tochnit85`.
2. דחוף את התיקייה:
   ```bash
   cd tochnit85-android
   git init -b main
   git add .
   git commit -m "Tochnit 85"
   git remote add origin git@github.com:<USER>/tochnit85.git
   git push -u origin main
   ```
3. בלשונית **Actions** ירוץ `Build APK` (בערך 4–5 דקות).
4. בסיום תופיע ב-**Releases** גרסה עם הקובץ `tochnit85.apk`. פותחים את הדף מהטלפון, מורידים ומתקינים. בפעם הראשונה אנדרואיד יבקש לאשר התקנה ממקור לא ידוע.

## בנייה מקומית

- **Android Studio:** File → Open → התיקייה הזאת → Run.
- **שורת פקודה** (JDK 17 ו-Android SDK 34):
  ```bash
  ./gradlew assembleRelease
  # app/build/outputs/apk/release/app-release.apk
  ```

## עדכונים

הממשק כולו נמצא ב-`app/src/main/assets/index.html`. כל שינוי ודחיפה ל-`main` בונים גרסה חדשה עם מספר גרסה גבוה יותר. היא מותקנת מעל הקודמת והנתונים נשמרים, כי כל הבניות חתומות באותו מפתח.

## חשוב לדעת

- **מפתח החתימה בריפו:** `app/tochnit85.keystore` נמצא בריפו כדי שכל בנייה תהיה חתומה באותו מפתח. לכן הריפו צריך להישאר פרטי.
- **גיבוי:** הנתונים לא מסונכרנים עם גרסת הדפדפן. בפרופיל (הכפתור למעלה) יש "שתף קובץ גיבוי" ו"שחזר מגיבוי". כדאי לשמור גיבוי פעם בכמה שבועות, למשל לדרייב.
- **מסך דולק:** בזמן שלשונית האימון פתוחה המסך לא נכבה, והטלפון רוטט כשהמנוחה בין הסטים נגמרת.
